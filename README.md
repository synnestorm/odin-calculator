# Odin Project: Calculator

In this assignment I were to create a fully functional Calculator. This project is going to combine everything I have learned using HTML, CSS and JavaScript.

## Built with

- HTML5
- CSS3
- JavaScript

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone git@github.com:synnestorm/odin-calculator.git
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following commands:

```bash
npm run start
```
